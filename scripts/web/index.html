File và tên mặc định

Để trống thì nút “Thêm vào file quản lý” bị tắt. Trên Windows dùng dấu gạch chéo xuôi /.
Chỉ là gợi ý ban đầu — mỗi máy vẫn tự chọn tên trước khi lưu đơn.
Lưu vào config/config.yaml và .env, rồi nạp lại ngay — không cần khởi động lại.
